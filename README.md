# 🚀 Cypress Automation Learning Path - XAcademy

¡Bienvenido/a a mi repositorio de aprendizaje de QA Automation! Este espacio está dedicado a almacenar mis prácticas, proyectos y desafíos utilizando **Cypress**, desarrollados a lo largo del trayecto formativo en **XAcademy**.

El objetivo principal de este repositorio es consolidar los conceptos clave de la automatización de pruebas de software, desde los fundamentos hasta la creación de frameworks robustos y mantenibles.

## 📚 Plan de Aprendizaje (Semana a Semana)

El contenido de este repositorio está estructurado siguiendo el plan de estudios oficial de **XAcademy**, dividiéndose en los siguientes módulos semanales:

* **Semana 1: Fundamentos de QA**
  * Introducción al rol de QA, conceptos clave y metodologías de trabajo.
  * Bases y ejecución de **Testing Manual** (diseño de casos de prueba y reporte de bugs).
* **Semana 2: Setup y Control de Versiones**
  * Instalación y **Setup de Cypress** en el entorno local.
  * **Control de versiones** con Git y GitHub para la gestión del código de automatización.
* **Semana 3: Automatización Core**
  * Implementación de **Aserciones** y aplicación de **Buenas Prácticas** de automatización.
  * Creación y uso de **Custom Commands** para optimizar y reutilizar código.
* **Semana 4: Manejo de Datos y API Avanzado**
  * Uso de **Fixtures** para pruebas basadas en datos externos (Data-Driven Testing).
  * Introducción al **API Testing en Cypress** para validar respuestas del backend.
* **Semanas 5 a 7: Testing de APIs & Desafíos**
  * Dominio de pruebas de servicios con **Postman & API Testing** integrado.
  * Resolución de **Challenges** prácticos de automatización para consolidar lo aprendido.
* **Semana 8: Cierre**
  * Consolidación del proyecto final, revisión de buenas prácticas y finalización del trayecto formativo.

## 📁 Estructura del Proyecto

A grandes rasgos, la estructura de carpetas del proyecto se organiza de la siguiente manera:

* 📁 **cypress/**: Carpeta principal de Cypress.
  * 📁 **e2e/**: Aquí se encuentran los archivos de prueba (.cy.js / .cy.ts).
  * 📁 **fixtures/**: Archivos de datos estáticos (JSON) para pruebas basadas en datos.
  * 📁 **page-objects/**: Clases bajo el patrón Page Object Model (si aplica).
  * 📁 **support/**: Comandos personalizados (`commands.js`) y configuraciones globales.
* 📄 **cypress.config.js**: Archivo de configuración global de Cypress.
* 📄 **package.json**: Dependencias, librerías y scripts de ejecución del proyecto.
* 📄 **README.md**: Documentación del repositorio (este archivo).
